# Normativa municipal

**No se sube al repositorio.** Aquí va, por municipio, lo que depende de cada
expediente:

```
normativa/municipal/
└─ <municipio>/
   ├─ ficha-<ámbito>.pdf o .md     la ficha del sector o del ámbito, no el plan entero
   ├─ normas-urbanisticas.md       las normas del plan que apliquen
   └─ borm/                        lo que solo esté en el BORM: aprobaciones, decretos, órdenes
```

Dos reglas:

- **Solo lo que aplica.** Un plan general entero son decenas de páginas para una
  ficha de dos: se extrae la ficha del ámbito y las normas que toquen.
- **PDF con texto seleccionable, o Markdown.** Un escaneo no se puede citar
  literalmente. Si es una imagen, se dice y se transcribe lo que haga falta.
